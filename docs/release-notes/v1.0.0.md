# ExtendCast v1.0.0

ExtendCast 1.0.0 delivers a more configurable, responsive, and reliable
extended-display experience for macOS. This release adds per-device controls,
stabilizes virtual-display identity and HiDPI behavior, reduces background
overhead, and provides faster access through a native menu-bar controller.

## Highlights

- **Per-device settings** — Every receiver keeps its own resolution, density,
  Retina mode, bitrate, frame rate, audio, protocol, route, and auto-connect
  preferences.
- **Stable virtual displays** — Receiver and density identities remain
  consistent across launches, preserving display arrangement and preventing
  duplicate ColorSync profiles.
- **Smoother macOS display management** — Display updates avoid unnecessary
  virtual-monitor recreation, reducing WindowServer and ColorSync work that
  could make System Settings and display arrangement drag operations stall.
- **Menu-bar controls** — A compact panel shows the app name and keeps
  connect/disconnect icon actions aligned at the right edge of each device row.
  Open ExtendCast or quit without keeping the main window visible.
- **Custom resolutions** — Add, edit, validate, and remove resolution presets
  with understandable PPI and equivalent physical display-size information.
- **Universal Mac build** — One download supports both Apple silicon and
  Intel-based Macs running macOS 14 or later.

## Device and Connection Management

- Configure available receivers before connecting and adjust the same settings
  while connected.
- Apply settings to one receiver without restarting every active connection.
- Reconnect only when a transport-level change requires it.
- Store manual-IP connections as recent devices with availability and
  local-network privacy states.
- Discover TCP and UDP services simultaneously while preserving each device's
  selected protocol and route.
- Keep protocol preferences intact when AWDL falls back to another network
  route.

## Display Quality and Reliability

- Use stable serial, vendor, and product identifiers for each receiver and
  Standard/Retina density mode.
- Select the requested logical size and exact 1× or 2× backing-pixel mode after
  virtual-display registration.
- Update resolution and refresh rate in place whenever possible.
- Match virtual-display refresh rate to the selected 30 or 60 FPS stream rate.
- Cap Standard-mode display density at 110 PPI while retaining the configured
  PPI for Retina mode.
- Recover capture after wake, unlock, or login-session changes without replacing
  the virtual display or losing its arrangement.

## Performance Improvements

- Request the bi-planar `420v` capture format directly for VideoToolbox.
- Reduce ScreenCaptureKit queue depth to three frames to lower memory pressure
  and capture latency.
- Run screen and audio sample handling at utility priority so foreground input
  and window interactions remain responsive.
- Remove periodic full-resolution display screenshots from the main workflow;
  optional previews are captured on demand and downscaled.
- Render logs as one capped text block instead of hundreds of separate views.
- Start the receiver listener only when requested or enabled at launch.
- Serialize Windows FFmpeg and zero-copy presenter access to their shared D3D11
  immediate context, and acknowledge frames only after successful presentation.
- Recover Windows sessions from D3D device loss by switching to software decode
  and OpenGL at a fresh keyframe instead of continuing to use stale GPU objects.

## Interface Improvements

- Reorganized navigation for Devices, Recent, Connect, Receive Screen, Settings,
  and Logs.
- Added consistent macOS-style device cards and compact Settings, Apply, and
  Disconnect actions.
- Added connected-device status summaries and clearer pending-change behavior.
- Added Launch at Login management using the native macOS service API.
- Added in-app update checks against ExtendCast GitHub Releases and a
  pre-filled issue-reporting flow.

## Installation

1. Download `ExtendCast-v1.0.0-universal.zip`.
2. Extract it and move `ExtendCast.app` to `/Applications`.
3. Open ExtendCast and grant Screen Recording, Accessibility, and Local Network
   permissions when prompted.

This build requires macOS 14 or later. Automatic update detection checks the
latest published GitHub Release; draft and prerelease releases are not offered
as stable updates.
